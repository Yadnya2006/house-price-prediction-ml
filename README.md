# house-price-prediction-ml
# House Price Prediction using Linear Regression

This project predicts house prices using the California Housing dataset and a Linear Regression model.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Features

* Exploratory Data Analysis (EDA)
* Data Visualization
* Linear Regression Model
* Model Evaluation
* Saved ML Model
* Prediction Script

## Evaluation Metrics

* MAE: 0.533
* RMSE: 0.746
* R² Score: 0.576

## Files Included

* task1_ml_linear_regression.ipynb
* task1_report.pdf
* house_price_model.pkl
* predict_house_price.py
